# 休市日備援資料

這個資料夾的 `年份.json` 是證交所「市場開休市日期」的原始回應，下載後原封不動存放，作為休市日判斷的**備援**：
程式優先查官方 API，查不到（例如沒有網路，或驗收用的測試伺服器沒有這支 API）時改讀這裡的檔案。

網址格式：`https://www.twse.com.tw/rwd/zh/holidaySchedule/holidaySchedule?date={年份}0101&response=json`

| 檔案 | 下載日期 | 用途 |
|---|---|---|
| 2021.json～2025.json | 2026-11-21 | 2.0 網頁補登過去的交易時，提醒「這天可能不是交易日」（第 6 題 C8-6） |
| 2026.json、2027.json | 2026-11-20 | 第 3 題排程判斷今天有沒有開盤；2.0 網頁的提醒 |

**為什麼是這幾年**：官方目前只提供 2021～2027 年（2026-11-21 實測）；2020 年以前與還沒公布的年份，官方回 `stat: ok` 但 `data` 是空的。
空的清單程式一律視為「沒有資料」（不是「沒有休市日」）：排程把平日當成開盤日，網頁只檢查週末並註明。

**每年更新**（第 6 題 C8-7 b）：
- 伺服器有網路時會自動向官方取得新的年份，不更新這裡也能運作。
- 證交所公布隔年休市日後，用上面的網址（把 date 換成隔年的 0101）下載，存成 `隔年.json` 放進這個資料夾，作為沒有網路時的備援，並更新上表。
